# 鼠标快点

一款轻量的 macOS 原生系统级自动点击器。它按照设定间隔，在当前真实鼠标位置发送左键点击，可用于网页、Chrome 扩展弹窗、浏览器工具栏和其他 Mac 应用。

## 下载与安装

1. 打开 GitHub 仓库右侧的 **Releases**，下载最新的 `鼠标快点-v*-macOS.zip`。
2. 解压后，把 `鼠标快点.app` 拖入“应用程序”文件夹。
3. 第一次打开时，建议右键应用并选择“打开”。
4. 按提示前往“系统设置 → 隐私与安全性 → 辅助功能”，允许“鼠标快点”。

本项目没有使用 Apple Developer ID 公证。如果 macOS 阻止打开，可在“系统设置 → 隐私与安全性”底部选择“仍要打开”。

## 使用方法

1. 输入点击间隔，最短为 50 毫秒。
2. 点击“3 秒后开始”，在倒计时结束前把鼠标移到目标位置。
3. 鼠标位于“鼠标快点”面板内时会自动暂停，移出面板后自动继续。
4. 点击红色“停止点击”按钮即可停止。

快捷键：

- `⌥ Option + ⇧ Shift + S`：开始或停止
- `⌥ Option + ⇧ Shift + X`：紧急停止

## 从源码构建

需要 macOS 13 或更高版本，以及 Xcode Command Line Tools：

```bash
./build.sh
```

构建结果位于 `dist/`。本地源码构建使用 ad-hoc 签名，因此首次运行仍需在“辅助功能”中授权。

## 隐私

应用不会记录鼠标位置、按键内容、网页内容或浏览数据，也不会联网发送数据。
